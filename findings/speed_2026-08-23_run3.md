## R1 FIXED (was flagged by review, owned by nobody)

Reviewer finding R1: the parallel restructure saved per-leaf checkpoints
only in the ordered-assembly loop, which never runs if ANY leaf raised —
so one leaf's crash forfeited every other leaf's paid model calls,
breaking the W3 "resume from last good step" contract.
`test_review_checkpoint_partial_progress.py` failed at the merge point.

Fix (`a4786ee`, pushed): checkpoint saves moved INSIDE `_retrieve` /
`_answer_fresh`, immediately per completed leaf. Saves are atomic
(tempfile + os.replace) so concurrency is safe; trace.stages still appended
in leaf order during assembly (deterministic); error selection still
first-failing-leaf-order via gather(return_exceptions=True). The test now
passes WITH the parallel engine — contract restored, no de-parallelization.

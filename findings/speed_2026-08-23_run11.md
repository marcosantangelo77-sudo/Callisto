## THIS RUN'S MODULE — announced before edit

THE DEFECT: the run-7 fast path exists, is running, and the router cannot see
it by default. Same defect family as the original 2,625s baseline (94% of
every call was process startup) one layer up: not "a shell per call" any more,
but "the persistent backend is undiscovered unless a human exports an env var
in every shell". Out of the box, every question pays the CLI-fork startup tax
on all 6–7 of its model calls: at healthy-Portal pricing that is ~68–122s per
question vs ~8–15s discovered — the largest remaining measured cost.

THE FIX (config-declared discovery, no hardcoded port in code):
- providers.yaml gains `base_url_default: http://127.0.0.1:8646/v1` under
  `ox_alpha_proxy` (matches where `hermes proxy start` actually binds).
- `_endpoint_from_config` resolution becomes: explicit base_url → env →
  DECLARED DEFAULT → unresolved. Endpoints without a default behave exactly
  as today.
- Degradation when the proxy is NOT running: instant loopback refusal
  (measured 13ms), existing per-endpoint cooldown ladder suppresses repeat
  probes, failover chain unchanged — strictly the pre-run-7 behaviour plus
  sub-second discovery probes.
- api_key stays None when its env is unset (proxy accepts unauthenticated
  loopback requests — verified by headerless curl); model already has a
  literal default (`stealth/ox-alpha`), so OX_ALPHA_PROXY_MODEL stays
  optional exactly as now.

## FAMILY HUNTED — a NEW one, found at process scale

**10. A blind bulk-commit daemon plus silent-deletion merges turns any
worktree accident into master history.**

The autosave daemon commits `git add -A && git commit` every five minutes,
whatever is in the worktree, under a message that asserts its own safety
("so nothing is lost"). At 09:48 on 08-24, db08c13 landed two verified
defect fixes on master (C5 compute↔stance reconciliation, quant-gate
tightening). At 10:24, cd7f068 — an autosave snapshot on
`fix/worldbank-planner` whose tree did not have that morning's work —
committed, in one stroke:

  - reversion of both C4/C5 engine features (`reconciliation_failure`,
    `_sole_bare_boolean`, `_produced_quantitative`, asked-vs-answered notes,
    `n_sources_answered` — all absent from HEAD's engine.py),
  - deletion of THREE reviewer repro suites (35 failing repros),
  - deletion of six findings documents and `scripts/discriminate_goldens.py`,
  - reversion of the speed goldens regenerated for C5.

Every 5-minute autosave for the next three hours enshrined the destruction.
The 17:51 merge train then propagated all of it to master without friction.
**Git makes source conflicts loud and deletions silent** — a merge that
deletes other agents' tests and verified fixes looks identical to one that
adds a planner. The post-mandate "merge, then RUN THE SUITE" step either did
not run or was ignored: master is red right now (see R1).

This is PATTERNS family 7 ("deleting the red tests manufactures confidence")
and family 2 ("a fix lands in one copy while another keeps the bug") executed
mechanically at repo scale, with family 4's signature: a LABEL
("autosave: in-flight work") deciding what reaches master.

**It recurs.** The same daemon committed a half-restored state to THIS
reviewer's branch mid-session (d475732, 19:24). And reviewer run 12 found
the whole thing independently 13 minutes after the merge landed
(d1a1396 on `improve/money-path-landing`) — where the finding is still
stranded, because that branch is unmerged. Nobody reads stranded branches;
that is how a caught defect stays live.

**Fix direction:** autosave must commit only paths the owning instance
touched (or at minimum never commit deletions without an allowlist);
merges must diff against master and list deletions of files not owned by
the branch for explicit confirmation; the merge train must run the suite.

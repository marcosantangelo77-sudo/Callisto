profiled defect is in `ProviderRouter._post` (inference.py ~line 1384) and
`check_health` (~1316): a **fresh `httpx.AsyncClient` per request**. Every
completion pays TCP connect + TLS handshake from scratch; no connection ever
reused across the 6+ calls of one pipeline run, let alone across runs. This is
the per-call transport-overhead class, HTTP tier. Fix: one shared, lazily
created AsyncClient (connection pooling / keep-alive), per-request timeout
override preserved, failover semantics untouched.

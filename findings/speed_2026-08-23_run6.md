## THE FIX: ProviderRouter shares one pooled AsyncClient

`_post()` (inference.py) built `async with httpx.AsyncClient(...)` per request;
`check_health()` did the same. Every completion and every health probe paid a
fresh TCP connect + TLS handshake — the same per-call-overhead disease as the
CLI startup defect, one layer down, on every non-local endpoint.

Fix: `ProviderRouter._shared_client()` — one lazily-created pooled client,
bound to the creating event loop and rebuilt if the loop changes (asyncio
transports are loop-bound). Per-request timeout still passed on each post.
Failover/retry/budget paths untouched.

### P1 — C2's scope filter is load-bearing and completely unpinned

Deleting `checkpoints = [ck for ck in checkpoints if ck.run == trace.run]`
(seal_guard, checkpoint.py:417) reintroduces cross-run laundering on every
resumed run sharing a checkpointer root — the default root IS shared
(`$CALLISTO_STATE_DIR/callisto/checkpoints`, FileCheckpointer.__init__) —
and **all 7 shipped C1+C2 tests stay green**. Verified by simulation:
without the filter, a resumed run B absorbs run A's bytes as PRIMARY; with
it, it doesn't. Why the shipped pins miss it:
`test_redteam_c2_crossrun_laundering.py`'s two laundering tests use FRESH
traces, where replay goes to the scratch ledger and the filter is dead
weight; the resumed-path test only uses this-run checkpoints. The
interesting branch has zero coverage. Fixed here by adding the missing pin
(`TestC2ScopePinOnResumedBranch`) plus a source-level control.

### R5 — a seventh inflation path: claims.recompute_confidence rounds UP to the ceiling

ba0a63c's headline says six inflation paths, all closed by "ONE shared
quantiser used by every site". `agp/claims.py:141,145` was not one of the
six and still uses `round()`:

```
recompute_confidence([SECONDARY evidence], claimed=0.7499) == 0.75   # RAISED
recompute_confidence([INFERRED evidence],  claimed=0.5451) == 0.55   # RAISED
```

The clamp exists to hold a claim DOWN to what evidence warrants; rounding
lets it land exactly AT the ceiling from below — the same shape as the F2
pin (`clamp_parent_confidence(0.7499) == 0.74`) fixed in 96be252. Its
docstring even claims "identical behavior to orchestrator's clamp" — the
clamp that WAS floored. Reachable without any test seam: `Claim.attach()`
passes `evidence.confidence_score` straight in (claims.py:221), and model-
supplied confidence scores are arbitrary floats. This is the long-lived-
claims path — the BeliefRecord journal — so a raised value is also
hash-chained into history. Repro: `TestR5ClaimsClampRoundsUp`
(xfail strict=True), controls prove floor_conf floors the same input.
Same-family, lower stakes: `tools/research_program.py:243`
`round(min(score, src_cap), 4)` can raise by ≤5e-05.

## THE NEXT BOTTLENECK (measured, not guessed)

Run 7 shipped the persistent proxy; run 8 made transient 429s retry. Tonight
measures that **the win never engages by default and throws itself away under
exactly the load it was built for**:

1. **Dormant by default.** `ox_alpha_proxy` resolves its URL only from
   `OX_ALPHA_PROXY_BASE_URL`. Nothing in the repo ever sets it — so every real
   pipeline process routes research_synthesis to `[gpu1 (dead), frontier
   (unresolved), ox_alpha_proxy (unresolved), ox_alpha (no binary)]` and dies.
   The 6–15× per-call win requires an undocumented manual env export.
2. **The 429 policy kills the serving path under capacity pressure.**
   - `Retry-After` ≤ 10 → blind sleep of the FULL header value (measured 10s)
     before an in-place retry that then serves in ~2.6s.
   - `Retry-After` = 30 (observed tonight) > cap 10 → raise immediately →
     failover lands on `ox_alpha` hermes_cli → **FileNotFoundError** → whole
     call fails. Run 8 priced failover at "~14s"; on a machine without the
     CLI binary it is infinite.
